Decisions: **layout contract** (`layout.d.ts`, the keys contract's shape: a header comment saying what the app keeps, inputs, the kit, `Layout` with every part optional, `CompleteLayout extends Required<Layout>`). The inputs are view-model records, never the snapshot:
           ```ts
           export type UsageTone = 'normal' | 'warning' | 'critical';
           // `text` is what the meter reads (`42%`, or `180k/300k` for context); `percent` is 0–100.
           export interface MeterInput { label: string; text: string; percent: number; tone: UsageTone }
           export interface SessionLineInput { context: MeterInput; cache: string | null; spend: string | null }
           export interface StatusLineInput {
             session: SessionLineInput | null; profileName: string | null;
             plans: readonly MeterInput[]; note: string | null; stale: boolean;
           }
           export interface DetailsRowInput extends MeterInput { resets: string | null }
           export interface DetailsProfileInput {
             name: string; isDefault: boolean; state: 'fresh' | 'stale' | 'error' | 'loading';
             rows: readonly DetailsRowInput[]; extraUsage: string | null; freshness: string; error: string | null;
           }
           export interface DetailsSessionInput {
             context: MeterInput; window: string; configuredLimit: string; reportedLimit: string;
             remaining: string; limitsDiffer: boolean; cache: string; spend: string;
           }
           export interface DetailsInput { profiles: readonly DetailsProfileInput[]; session: DetailsSessionInput | null }
           export interface UsageKit extends BaseKit {
             // A Meter primitive filled to `percent` in `tone`, appended to `parent`.
             meter(parent: HTMLElement, percent: number, tone: UsageTone): HTMLElement;
           }
           export interface Layout {
             statusLine?(parent: HTMLElement, input: StatusLineInput, kit: UsageKit): HTMLElement;
             details?(parent: HTMLElement, input: DetailsInput, kit: UsageKit): HTMLElement;
           }
           ```
           **profile the line shows** (design.md § The usage plugin): the shown session is `sessions.selectedSessionId()` at start, then each `sessions.activeChanged`. Its `SessionUsage` names its `profileDir`; the line shows the plan whose `profileDir` equals it (plain equality, plan.md § File Structure). The default plan (`isDefault`) shows while no session shows, while the shown session has no `SessionUsage` (a session chat does not own), and when no plan has the session's `profileDir`. `session` is null whenever the shown session has no `SessionUsage` or its `usage` is still null (opened, no turn ended yet; 05 records the session's profile when chat opens it): the profile half still follows its `profileDir`
           **context** (design.md § Vocabulary, Autocompact limit): the limit is `autocompact.configured`, else `autocompact.reported`. With a limit: `text` is `<formatTokens(used)>/<formatTokens(limit)>`, `percent` is `min(100, used / limit * 100)`; with none: `text` is `formatTokens(used)`, `percent` 0, tone `normal`. `label` is `Context`. The context tone is the app's own grading (design.md: "the context bar by its share of the limit"): below 70 % `normal`, below 90 % `warning`, else `critical`. A plan meter's tone is its row's `severity`, its `label` the row's `label`, its `text` `formatPercent(row.percent)`, its `percent` the row's
           **status line notes**: `note` replaces the plan meters: `plan loading` (usage null, no error), `plan unavailable` (usage null, error set), `no plan rows` (usage with no rows), `no profiles` (the snapshot holds no plan; `profileName` null). `stale` is the shown plan's `stale` while it has usage. `cache`: null when `cacheExpiresAt` is null, `cache cold` when it is not later than now, else `cache <formatDuration(cacheExpiresAt − now)>`. `spend`: null when `spendUsd` is null, else `formatUsd(spendUsd)`
           **details**: one `DetailsProfileInput` per plan in snapshot order. `state`: `loading` (usage null, no error), `error` (usage null, error set), `stale` (usage set, `stale`), else `fresh`. `freshness`: `updated <ago>` (fresh), `stale, last good <ago>` (stale, from `lastGoodAt`), `no good read yet` (error), `loading` (loading), where `<ago>` is `just now` under one minute, else `<formatDuration(now − at)> ago`. `extraUsage`: null when the usage or its `extraUsage` is null, `off` when not enabled, else `<formatMinor(usedMinor ?? 0, currency)> / <limit>` with `<limit>` `formatMinor(limitMinor, currency)` or `no limit` when `limitMinor` is null. A row's `resets`: null when `resetsAt` is null, `resets now` when not later than now, else `resets in <formatDuration(resetsAt − now)>`. `session`: null as for the line; else `context` as the line's, `window` `formatTokens(contextWindow)` or `unknown`, `configuredLimit` `formatTokens(configured)` or `none`, `reportedLimit` `formatTokens(reported)` or `unknown`, `limitsDiffer` true only when both limits are set and unequal, `remaining` (the user's requirement: context left before autocompact) `<formatTokens(max(0, limit − used))> left` against the line's limit, `past the limit` when used exceeds it, or `unknown` with no limit, `cache` `unknown` / `cold` / `expires in <duration>`, `spend` `formatUsd(spendUsd)` or `unknown`
           **formats** (`usage-format.ts`): `formatTokens`: below 1 000 the whole number; else `k = Math.round(tokens / 1000)`, and below 1 000 k `<k>k`; else millions rounded to one decimal, a trailing `.0` dropped, `<m>M`. `formatPercent`: `<Math.round(percent)>%`. `formatUsd`: `$` and two decimals (`toFixed(2)`). `formatMinor`: with a currency, `Intl.NumberFormat('en-US', { style: 'currency', currency })` of `minor / 10 ** digits`, `digits` that format's `resolvedOptions().maximumFractionDigits` (so JPY has none); with no currency, `minor / 100` to two decimals and no symbol. `formatDuration` (floors every unit): below 60 000 ms `<1m`; below an hour `<m>m`; below a day `<h>h <m>m`; else `<d>d <h>h`

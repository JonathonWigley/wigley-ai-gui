           **`readPlanUsage`**: reads `stdout` line by line and takes the first line that parses as JSON with `type: 'assistant'` and an object at `usage_report.rate_limits` (a top-level field of the line, beside `message`; measured). None → throw `claude -p /usage printed no usage report`. Each `limits[]` item with a string `kind` and a number `percent` becomes a row, in order; any other item is skipped. No row → throw `claude -p /usage reported no plan limits`. Per row: `group` the string `group`, else the kind; `label` is `scope.model.display_name`, else `scope.surface.display_name`, else `KIND_LABELS[kind]` (`{ session: '5h', weekly_all: 'Week' }`), else the kind itself, so a row the server adds shows under its own kind name; `percent` as sent; `resetsAt` `Date.parse(resets_at)`, null when absent or not a date; `severity` the string when it is `normal`, `warning` or `critical`, else `normal`; `isActive` `is_active === true`. `extraUsage` is null when `extra_usage` is not an object, else `{ enabled: is_enabled === true, usedMinor: used_credits, limitMinor: monthly_limit, currency }`, each number or string kept and anything else null. `at` is the argument
           **`rateLimitRows`** (the decoder calls it with the line's `rate_limit_info`): `unifiedWindows.five_hour` → kind `session`, `unifiedWindows.seven_day` → kind `weekly_all`, in that key order; any other key is skipped. A window without a number `utilization` is skipped. `percent` is `Math.round(utilization * 100)`; `resetsAt` is `resetsAt * 1000`, null when not a number; `severity`: `allowed` → `normal`, `allowed_warning` → `warning`, `rejected` → `critical`, any other → `normal`. No row → null

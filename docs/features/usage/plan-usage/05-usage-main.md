           **poll result** (`withPollResult`): for a `profileDir` no plan holds, the same state. On `ok`: `usage` is the result, `lastGoodAt = usage.at`, `error: null`, `stale: false`; then the held patches of that profile fold: a held patch whose `kind` the new rows hold and whose `at` is later than `usage.at` folds into the rows, one whose kind they hold and whose `at` is not later is dropped (the poll is fresher), and one whose kind they still lack stays held.            **poller** (`plan-poller.ts`), over injected deps and no global timer:
           ```ts
           export interface PlanPollerDeps {
             timers: Timers;
             clock: Clock;
             profiles(): readonly ChatProfile[];
             intervalSeconds(): number;
             planUsage(profileDir: string | null): Promise<PlanUsage>;
             roundStarted(profiles: readonly ChatProfile[]): void;
             polled(profile: ChatProfile, result: PollResult): void;
           }
           ```
           A round reads `profiles()` once, calls `roundStarted` with them, then calls `planUsage(profile.configDir)` for each profile with no poll still running, keyed by `configDir`; a profile whose poll still runs is skipped, so no profile has two polls in flight. Each settled poll calls `polled` with `{ ok: true, usage }` or `{ ok: false, error: errorText(reason) }`. `start()` runs a round at once and arms the timer. The timer fires a round and re-arms for `max(intervalSeconds(), MIN_POLL_SECONDS) * 1000` ms, read at each arming; a round's start time comes from `clock.now()`. `reschedule()` clears the timer and arms it for the last round's start plus the interval read now, or runs a round at once when that time is not later than `clock.now()`. `pollNow()` runs a round at once, re-arms the timer from that round, and resolves when every poll that round started has settled (task 07's drive action). `dispose()` clears the timer, and later results of running polls call nothing. `MIN_POLL_SECONDS` keeps a mistyped `0` from spawning `claude` without pause

- **Neutral request (pinned).** No app code names Claude's fields (plan § Boundary rules), so the script maps them:
  `{"tool": "edit" | "write" | "commit", "paths": [<absolute path>, ...], "agentId": <agent_id or null>, "cwd": <cwd>}`
  Edit, MultiEdit and NotebookEdit → `edit`; Write → `write`; Bash running `git commit` → `commit`. `agentId` is the input's `agent_id`, null when absent (the main agent). `cwd` is the input's `cwd`.
- **Which calls send.** `pre`: Edit, Write, MultiEdit, NotebookEdit, and Bash whose command runs `git commit`. `post`: Edit, Write, MultiEdit, NotebookEdit. The path is `tool_input.file_path`, or `tool_input.notebook_path` for NotebookEdit. Every other input, a Bash command with no `git commit`, an input that is not a JSON object, or a missing field → `request_from_input` returns None and the script prints nothing, opens no channel and exits 0. This also covers a host other than Claude that runs the file with another input shape.
- **Time budget (decided).** `main` reads `time.monotonic()` first and sets `deadline = start + HOOK_DEADLINE_SECONDS`. Every git call runs with `min(GIT_TIMEOUT_SECONDS, deadline - now)` and is skipped (returns None) when no time is left. The app exchange gets the time left: `ask_app` opens the channel with `timeout=deadline - now`, calls `set_timeout(deadline - now)` before each `write` and each `read`, and returns None when no time is left or when the line is not complete by the deadline. A reply that arrives a few bytes at a time therefore cannot run past the deadline. When the deadline passes anywhere, the script prints nothing and exits 0. The deadline stays under Claude's own 5 s `timeout`.
- **Commit paths (decided).** A `git commit` commits staged paths plus any pathspec it names, so `commit_paths` sends their union, absolute:
  - Tokenize: `lexer = shlex.shlex(command, posix=True, punctuation_chars=True)` with `lexer.whitespace_split = True`, then `list(lexer)`; a `ValueError` → None. With these settings `x&&git` and `a;` split into separate tokens. An operator token is one made only of the characters `();<>|&`.
  - Find the commit: scan the whole token list for the first `git`, then optional `-C <dir>` / `-c <k=v>` pairs, then `commit`. A `git` that is not followed by `commit` after those pairs is skipped, and the scan goes on. No match → None (not a commit). Only the first `git commit` in the command counts. Earlier commands on the line (`cd x &&`) are not a reason to return None.
  - Cut the commit's own tokens at the next operator token after `commit`: tokens after it (`&& git push`) belong to another command.
  - **Earlier `git add`.** The hook runs before the earlier commands on the same line. For each `git … add` that sits before the commit, up to its own operator token, add its pathspec (every token not starting with `-`, and every token after `--`). That pathspec joins the union, so `git add a.ts && git commit -m x` sends `a.ts`.
  - `-C <dir>` sets the folder git runs in, relative to `cwd`.
  - Pathspec: every token after `commit` that does not start with `-`, skipping the value after each option that takes one: `-m`, `-F`, `-C`, `-c`, `-t`, `--message`, `--file`, `--author`, `--date`, `--template`, `--reuse-message`, `--reedit-message`, `--fixup`, `--squash`, `--cleanup`, `--trailer`, `--pathspec-from-file`. An option written with `=` takes no next token. Every token after `--` is pathspec. The script does not read a `--pathspec-from-file` file: the paths in it are not sent.
  - **Short-flag clusters.** Read a cluster such as `-am` letter by letter, up to the first value-taking letter (`m`, `F`, `C`, `c`, `t`). That letter and the rest of the cluster are its value (when the letter is last, the next token is the value). So `-am` is `-a` plus a message, and `-ma` is a message `a` with no `-a`.
  - **Only.** `-o` or `--only` (also as a letter in a cluster, read as above) means the commit takes the pathspec alone: skip the staged and tracked reads, and send only the pathspec.
  - Staged: `git diff --cached --name-only -z`. With `-a` or `--all` (or a cluster that holds `a` before any value-taking letter), add `git diff --name-only -z` (tracked changes). Union order: staged, tracked, earlier `git add` pathspec, then the commit's pathspec.
  - Make each path absolute against `git rev-parse --show-toplevel`; make each pathspec token absolute against the git folder. A pathspec that names a folder is sent as that folder; 08's pre handler expands it (08's pass adds that).
  - `run_git(args, cwd)` (from `git_runner(deadline)`) runs `git` within the time budget above and returns stdout, or None on a non-zero exit, a timeout or a missing git; a None from any git call → `commit_paths` returns the paths it has so far. Deduplicate, keep first-seen order.
  - A command that only names `git commit --amend` with nothing staged sends `[]` paths; 08 then finds no hit.
